### 使い初めに気を付けること

- 最低限のフォルダ構造は作る
- tagを使う。テンプレートにもタグをつけておき、テンプレート使用時に自動でtagがつくようにしておく。

### 運用中に気を付けること

- 自分が書いている項目と、ページのタイトルを一致させる。
- ２回以上記述される項目は、新しいページを作って"固有名詞"にする。空白のページでもよいと思う。linkを作るオブジェクトを作ることが大切。
- graph viewを最低限きれいに保つ
    - 特定のフォルダは非表示にする、特定タグを非表示にするなどの手段で。自分が何を見たいのか、何を忘れたうえで保存しておきたいのかを考える。
- 定期的に整理する。folder構造を使ってもいいし、tagを使ってもいい。software的に分類する手段さえ何かあれば、その先にどう表示するかはなんとかなるのがobsidianの良いところ。

## Obsidianのデバイス間同期について

選択肢として

- Obsidianのデバイス間同期は、公式のObsidian Syncを使う

    -> 最大容量を初期に超えてしまって選択外になってしまった。

- obsidian git pluginを使う

    -> タイミングのコントロールが自分にないのが嫌だった。

- Cloud Storageを使う

    -> gitとicloudが両立しなかった（git repositoryが壊れた）のでやめた

- 自分でgitを使う

    -> 今ここ

結局自分はgitを直で使っています。obsidian vaultのフォルダ内にpythonのスクリプトとかもおいてるので、gitで管理することにあまり違和感はないです。

## 自分のフォルダ構造（抜粋）

/Note/daily_personal/yyyy-mm-dd.mdに日々の記録を書く。それをweekly、monthly、quarterly、half_yearly、yearly、decadeのページにまとめていく。そこに登場する'固有名詞'は、object database, personal_wikiに登録していく。

daily_note -> weekly_note -> monthly_note -> quarterly_note -> half_yearly_note -> yearly_note -> decade_noteのローリングアップのプロセスはgenerative aiとかも使いながら。
