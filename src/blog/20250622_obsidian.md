## Obsidianを使い始める際のポイント

- 最低限のフォルダ構造は作る
- tagを活用する。テンプレートにはあらかじめタグをつけておき、自動で付与されるように設定しておくと便利。

## 継続運用で気を付けていること

- 書いている項目とページタイトルを一致させる。
- 2回以上登場する項目は、新規ページを作成して「固有名詞」として扱う。内容が空白でもリンクとして役立つ。
- Graph Viewはシンプルで見やすい状態を保つ。
    - 不要なフォルダや特定のタグを非表示にする。
    - 自分がよく使うものや、後で見返す可能性があるものを明確にする。
- 定期的に整理する。
- フォルダやタグで整理。Obsidianの柔軟性により分類さえしておけば後から表示方法は自在。

## Obsidianのデバイス間同期について

同期の方法は色々ありますが、私が検討したものは以下です。

- Obsidian Sync（公式）
    - 初期容量制限を超えてしまったため不採用。
- Obsidian Git Plugin
    - 自動同期のタイミングを自分で制御できないのが嫌だったため不採用。
- クラウドストレージ利用
    - Gitとの相性が悪く、Gitリポジトリが破損したため不採用。
- Gitを手動で管理
    - 現在の運用方法。
    - Pythonスクリプトなども同時に管理できて便利。
    - 手動管理のほうが確実にファイル管理が行えるため選択した。



## 自分のフォルダ構造（抜粋）
毎日の記録をnotes/daily_personal/yyyy-mm-dd.mdに書き、以下の流れで情報をローリングアップしています。
```
daily → weekly → monthly → quarterly → half-yearly → yearly → decade
```
各段階で「固有名詞」はobject_databasesやpersonal_wikiに追加しています。このプロセスではGenerative AIも活用しています。
